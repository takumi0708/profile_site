# Next.js Practice App

JavaScript / React / Next.js / Tailwind CSS の基礎を学習するためのWebアプリケーション。

## 目的

Webアプリケーション開発の基本的な流れを理解し、
JavaScript / React / Next.js を使って自力で実装できるようになることを目的とする。

## 使用技術

- JavaScript
- React
- Next.js
- Tailwind CSS
- Git / GitHub

## 最終目標

学習記録を管理するWebアプリケーションを作成する。

- 学習記録の追加・表示・編集・削除（CRUD）
- Next.jsによるルーティング
- Reactによる状態管理
- データベースへの保存
- API / サーバー処理

最終的に、基本的なWebアプリケーションをゼロから自力で実装できる状態を目指す。
