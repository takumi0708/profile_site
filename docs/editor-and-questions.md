# プレビュー・スクリーンショット・質問コーナー

## 追加SQL

既存の001〜004に続けて、Supabase SQL Editorで次をそれぞれ一度実行してください。

1. `supabase/migrations/202609210005_screenshots.sql`
2. `supabase/migrations/202609210006_question_corner.sql`

005はStorageの`screenshots`バケット（公開画像用）と管理者専用のアップロード権限を作成します。
006は投稿先を持たない質問コーナーの受付と、公開質問のカテゴリ一覧を追加します。
既存のコメント・回答は引き継ぎます。

## 管理者の編集

質問文・回答・Projects本文・自己紹介に「プレビュー」ボタンがあります。
公開画面と同じMarkdown表示で確認し、「編集に戻る」で書き続けられます。
回答・Projects本文・自己紹介ではスクリーンショットを選択、または画像を貼り付けると、
末尾に画像のMarkdownが挿入されます。代替テキストは`![スクリーンショット]`の部分を編集できます。
PNG/JPEG/WebP、1画像5MBまで。アップロード中は本文保存を待ちます。

画像はアップロードした時点でURLから閲覧できます。下書き専用の非公開画像ではありません。
画像記法や投稿を消してもStorageの画像は残ります。不要な画像はSupabaseのStorage画面から削除できます。

## 閲覧者向け

- `/questions`：文字のみの質問コーナー。トップページとInterview一覧から開けます。
- ログインなしで投稿でき、管理者が回答・公開するまで他の閲覧者には見えません。
- 画像・Markdownは閲覧者の質問やその回答では展開せず、文字として表示します。
- 通知・再送・削除・連投制限は既存のコメントと共通です。
- `/interview`：公開済みの質問があるカテゴリを選択できます。カテゴリ内も1ページ10件です。
- カテゴリ変更時は1ページ目に戻り、次／前ページに進んでも選択を維持します。

## 確認

`node --test tests/comments.test.mjs tests/portfolio.test.mjs tests/screenshots.test.mjs`

SQL適用後、管理者で画像を選択／貼り付け→プレビュー→保存→公開画面の画像表示を確認してください。
StorageのHTTP経由のサイズ・形式チェック、ブラウザ上のクリップボード操作は実環境で確認が必要です。
閲覧者の質問投稿→通知→回答公開、およびカテゴリを選んでページを切り替える操作も確認してください。
