# 投稿とトップページの編集

## セットアップ

Supabase SQL Editorの新しいクエリで `supabase/migrations/202609200004_profile.sql` を一度実行します。
これはトップページの自己紹介・リンク用テーブルです。既存の質問とProjectsは変更しません。
既存のタグ用SQL（002）を適用済みなら、Projectsの登録・Markdown・ページ切り替えは追加SQLなしで使えます。

## ダッシュボード

- Projectsの管理：タイトル・本文・使用技術・タグを入力して登録。公開チェックなしなら下書きです。
- 登録済みプロジェクトのタイトルをクリックして編集。削除時は確認チェックが必要です。
- トップページの自己紹介・リンク：表示名、自己紹介、X・GitHubなどのリンクを編集して保存。
- リンクは1行に1件、`GitHub | https://github.com/yourname` の形式です。行を消すとリンクも削除できます。

## Markdown

質問文、回答、Projectsの本文、自己紹介に対応しています。
見出し（`##`）、太字（`**文字**`）、箇条書き、リンク、表、コードブロックなどを利用できます。
HTMLは実行・表示しません。既存の通常テキストもそのまま表示できます。

質問一覧は公開済みの質問だけを1ページ10件、作成日時の新しい順に表示します。
カードの回答プレビューはMarkdownの装飾を除いた先頭20文字です。続きがある場合は「…」を付けます。

## 確認

`node --test tests/portfolio.test.mjs`、`npm run lint`、`npm run build`。
接続先では下書き→公開→編集→削除、11件以上ある場合のページ切り替え、プロフィール変更の反映を確認してください。
